# XR guide moved

XR rendering, runtime setup and input now belong to the separate
`i4h-standalone-simulator` application. Its `docs/xr.md` contains the setup guide.
Use `i4h-sim` there, or the optional `i4h-isaaclab-standalone` bridge's `i4h-lab-teleop`
for Lab teleoperation. See [split migration](standalone-split.md) for moved symbols and commands.
