# Reproducing catheter and guidewire validation

[Validation report](../CATH_GDWR_VALIDATION.md). These checkout-based scripts use the workspace RodDirect solver. They include the experimental inputs, reference geometry, saved predictions, three-dimensional error metrics and report figures. Commands below start in `numerical_sim/`. Reruns write to this validation folder.

## Environment and quick check

```bash
uv sync --locked --group dev
export BENCH_PYTHON="$PWD/.venv/bin/python"
V=endoluminal/validation
"$BENCH_PYTHON" "$V/guidewire_solver_bench.py" --wire amplatz-extra-stiff --dt .016 --substeps 16 --stroke-mm .3 --output /tmp/amplatz-bend.csv
uv run --locked --with matplotlib python "$V/figures.py"
```

The figure command uses the two saved fine-step force traces, the coarse-step baselines and saved phantom predictions. It produces both overview figures and the nine instrument overlays. RMS and endpoint distances use all three spatial axes. The silhouettes show the registered x–z projection.

## i4h guidewire bending

```bash
"$BENCH_PYTHON" "$V/harrison_i4h/run.py" --jobs 4
uv run --locked --with matplotlib python "$V/harrison_i4h/analyze.py"
"$BENCH_PYTHON" "$V/harrison_i4h/baseline_1ms.py"
"$BENCH_PYTHON" "$V/harrison_i4h/1ms_stiffness_sweep/calibrate.py"
```

The first campaign runs the 11 Harrison shafts across timestep, mesh, damping and force-control configurations. The analyzer reconstructs the digitized points from saved figure-pixel coordinates. The second campaign runs 16 substeps per 16 ms frame. The sweep uses these traces to fit EI multipliers, then reruns the fitted inputs. See [fine-step results](harrison_i4h/summary.csv), [1 ms results](harrison_i4h/16ms_16substeps/comparison.csv) and [verified fits](harrison_i4h/1ms_stiffness_sweep/verified_fits.csv).

## Coupled i4h three-point bend on CPU and CUDA

The [coupled fixture](rod_coupled_gpu/README.md) runs all 15 prescribed-displacement
cases at a 1 ms substep and compares them with the archived SOFA and Newton VBD
curves. It solves the sliding-guide and nose reactions together with RodDirect's
internal constraints. The original split-projection benchmark remains the
reference for the historical measurements in the report.

## SOFA and Newton comparisons

Export `SOFA_ROOT` to the SOFA 25.12 installation directory containing `lib/` and `plugins/SofaPython3/` for Python 3.12. Export `NEWTON_ROOT` to a Newton v1.8.0 source checkout at commit `425db81f01e402b51f96f560e154d529d645c6de`. Native VBD and XPBD use a CUDA device. The launchers put these packages on the path only for the relevant subprocess. i4h continues to use the workspace’s locked Newton dependency.

```bash
"$V/harrison_sofa/run.sh"
"$V/harrison_sofa/run.sh" --force-control
"$V/harrison_vbd/run.sh"
"$V/harrison_vbd/run.sh" --iterations 32 --output "$V/harrison_vbd/refinement_32_iterations"
"$V/harrison_vbd/run.sh" --force-control
uv run --locked --with matplotlib python "$V/compare_harrison_backends.py"
"$BENCH_PYTHON" "$V/imperial/catheter_bending/run.py"
"$BENCH_PYTHON" "$V/imperial/catheter_bending/analyze.py"
for n in 8 32; do
  PYTHONPATH="$NEWTON_ROOT" "$BENCH_PYTHON" "$V/xpbd/bench.py" --iterations "$n" --output "$V/xpbd/xpbd$n.csv"
done
"$BENCH_PYTHON" "$V/xpbd/summarize.py"
```

The native cable uses VBD. The XPBD script first checks that the pinned solver rejects native rod joints, then runs the separate D6 articulated model on all four catheters. Compare [catheter forces](imperial/catheter_bending/summary.csv) and [XPBD results](xpbd/summary.csv).

## Elastrat phantom

The public worktree uses `cap_open_ends: false` in the Elastrat fixture to
preserve the original open query mesh. With that option, the public replay
reproduced all 45 archived centrelines and comparison rows exactly.

```bash
"$BENCH_PYTHON" "$V/imperial/shaft_inputs.py"
"$BENCH_PYTHON" "$V/elastrat/run.py" all
"$BENCH_PYTHON" "$V/elastrat/check_lumen.py"
uv run --locked --with matplotlib python "$V/figures.py"
```

The headless runner generates case YAMLs and per-edge material presets, loads them through i4h-endoluminal and measures each scan at its own inserted length. Use `catheters`, `guidewires` (uniform straight shafts) or `guidewires_profiled` in place of `all` for a subset. The catheter cases use the saved [310 mm station inputs](imperial/catheter_bending/inputs.csv), regenerated by the catheter bending runner. Compare [catheter](elastrat/catheters/results.csv), [uniform guidewire](elastrat/guidewires/results.csv) and [profiled guidewire](elastrat/guidewires_profiled/results.csv) results. Each folder also has the saved rod centrelines (metres, root to tip) and closest-face lumen diagnostic.

## Experimental inputs and provenance

Rebuild the 676 station measurements and the 388 Cook P1 force samples from the [two original workbooks and Figure 4](imperial/sources/) with the command below. The archive names were `Final result for catheter bending test.xls` and `Guidewire bending test results.xls`. The P1 curve records tester travel in mm and force in N.

```bash
uv run --locked --with xlrd --with pillow python "$V/imperial/extract_inputs.py"
```

| Input | Source and interpretation |
| --- | --- |
| Harrison bending targets | Published slopes in N/mm and standard deviations from Harrison et al. (2011). Larger-bend points come from Figure 2 and use the common onset estimate described in the report. |
| [Imperial modulus profiles](imperial/measured/flexural_modulus_profiles_SI.csv) | 514 guidewire and 162 catheter station measurements extracted from the Imperial guidewire and catheter bending workbooks. Distance from distal tip in metres and effective flexural modulus in Pa. |
| [Cook Straight P1](imperial/digitized/digitized_P1.csv) | Digitized tester travel and force from the Imperial guidewire bending figure. Linear regression over 2–5 mm with a 40 mm support span sets Cook’s shaft EI. Other wire rigidities use relative shaft-average modulus with a common effective section. |
| [CT centrelines](elastrat/phantom/references/) and [surface](elastrat/phantom/phantom.usdc) | Imperial Elastrat archive. The 27 NPY files contain original samples in metres, distal tip first. The mesh contains the inward-wound open phantom surface. Scan registration is common to every run. Depth suffixes 1–3 denote iliac bifurcation, aortic bifurcation and left renal origin. |

Source campaign: `korzen-nv/i4h-vascular`, revision `01831f0da4646d5bbc6ae45f86d23e6b1ad3a287`, report `CATH_GDWR_VALIDATION.md`. The original i4h campaign used revision `f772f330` with Warp 1.17.0. Harrison fixture results depend on numerical mass, mesh, substep and solver configuration. The CT comparison also depends on the assumed inlet, roll and frictionless contact.
